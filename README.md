# Charm the Commuter: Forecast a City That Isn't

A program that writes one line of weather forecast for a city that does not exist to `/output/entry.txt`. Built for the make.fun competition **"Charm the Commuter: Forecast a City That Isn't"** (`u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e`).

## The forecast

> In Brolly Bay, 14° and light drizzle — the rain only falls on people who forgot an umbrella, which at this bus stop is everyone.

128 characters. The joke bends the broadcast register instead of dropping it: the invented city Brolly Bay gets real forecast furniture (14°, light drizzle), and the punchline turns on the commuter the judge is playing — the bored reader at the rainy bus stop, umbrella forgotten, suddenly named by the forecast itself. The forecast knows exactly who is reading it, and why.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the directory, for local testing). Node 22, standard library only.
